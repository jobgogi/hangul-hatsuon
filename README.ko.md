# 한글 발음 (hangul-hatsuon)

[日本語](./README.md) | [한국어](./README.ko.md)

한글을 읽기 어려운 일본인을 위해, 한국어 문장을 카타카나 발음·로마자 표기로 변환해서 보여주는 브라우저 전용 도구입니다.

데모: https://jobgogi.github.io/hangul-hatsuon/

## 주요 기능

1. 입력한 한글 문장에 한국어 음운 규칙(연음·비음화·격음화 등)을 적용한 뒤, 카타카나 및 로마자 발음으로 변환한다.
2. Web Speech API의 TTS로 원문을 한국어(`ko-KR`)로 재생할 수 있다.
3. 문장을 음절 단위로 나누어 각 음절의 카타카나 발음을 함께 표시함으로써, 어떤 글자가 어떻게 읽히는지 파악하기 쉽게 한다.
4. 각 음절(또는 단어)의 카타카나 표기를 일본어(`ja-JP`) TTS로 그대로 재생해, 실제로 어떻게 들리는지 확인할 수 있다.

카타카나 표기는 어디까지나 근사치다. ㅓ/ㅗ, ㅡ/ㅜ, 평음/격음의 구분은 카타카나로 표현할 수 없으므로, 정확한 발음은 재생 음성으로 확인해야 한다.

## 사용법

1. 입력창에 한글 문장을 입력한다(샘플 태그를 클릭해도 된다).
2. 카타카나 발음·로마자 표기가 자동으로 표시된다.
3. "韓国語で再生"(한국어로 재생) 버튼으로 원문 음성을, 음절 카드의 "カタカナで再生"(카타카나로 재생) 버튼으로 카타카나 읽기 음성을 확인한다.
4. "カタカナをコピー"(카타카나 복사) 버튼으로 변환 결과를 클립보드에 복사할 수 있다.

TTS는 브라우저·OS에 설치된 음성(한국어/일본어)에 의존한다. 해당 음성이 없는 환경에서는 재생할 수 없다.

## 기술 스택

- React 19 + TypeScript + Vite
- ESLint (`eslint.config.js`)
- Vitest (`src/lib/`의 변환 로직 유닛 테스트)
- GitHub Pages (`gh-pages` 패키지로 `deploy` 브랜치에 게시)

## 개발

```bash
npm install
npm run dev       # 개발 서버 실행
npm run build     # 타입 체크 + 빌드
npm run lint      # ESLint
npm test          # src/lib/ 유닛 테스트 (Vitest)
npm run preview   # 프로덕션 빌드 미리보기
npm run deploy    # 빌드 후 deploy 브랜치에 게시
```
