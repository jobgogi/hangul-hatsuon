ハングルの発音をカタカナで

ハングルを入力すると、発音変化（連音・鼻音化・濃音化）を反映したカタカナ読みを表示します。音声は Web Speech API の韓国語音声で再生します。

例
カタカナ発音
{{ kanaAll }}
ローマ字（発音表記）
{{ romajaAll }}
速さ {{ rateLabel }}
{{ voiceNote }}
音節ごとの読み（クリックで再生）
{{ w.text }} {{ w.kana }}

カタカナは近似表記です。ㅓ / ㅗ、ㅡ / ㅜ、평음 / 격음 の区別はカタカナでは表せないため、実際の音は再生音声で確認してください。
